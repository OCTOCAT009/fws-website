Case Study · Clothing Brand · 2026

Turiya.

Enter the fourth state — philosophical streetwear, New Delhi

SectorStreetwear
LocationNew Delhi
Year2026
ScopeDesign + Build

The Client

Turiya is a philosophical streetwear brand built around consciousness — the fourth state of awareness in Vedic philosophy. Not trend-driven. A uniform for a mindset. Founded by Aish Madaan, its first drop is a single ungendered leather pant: the first word of a larger language.

A brand this specific cannot be sold from a template. The proposition is the atmosphere, and a stock product grid actively works against it.

What We Built

A full-bleed hero that drops the brand name hard, with no navigation competing for the first three seconds. A product page that presents the leather pant like art, not a listing — one garment, given the room a gallery would give it.

Then the part no theme ships with: a gamified rituals system. Nine interactive rituals that earn Khumari points, built into the browsing experience rather than bolted on as a loyalty widget. It rewards attention, which is exactly what a brand about consciousness should do.

Zero templates. Every element earning its place.

Where It Is Now

The site is live in pre-launch, with the waitlist gate up ahead of the first drop — so what you see at the link below is the signup, not the full storefront.
